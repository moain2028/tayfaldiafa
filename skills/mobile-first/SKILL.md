# الجوال أولًا

**لماذا:** المالك يقول إن 95% من عملائه على الجوال ([FACTS.md](../../docs/FACTS.md)). وجوجل تفهرس نسخة الجوال ([standards.md](../../docs/research/standards.md) البند 14). الأرقام والنصوص الرسمية في البند 16.

## ترتيب العمل
1. صمّم واكتب CSS لعرض 360 أولًا. الأعرض يُضاف بـ`min-width`.
2. ما لا يظهر على الجوال لا يُفهرس: لا محتوى لسطح المكتب فقط، ولا محتوى ينتظر نقرة ليُحمَّل. الأكورديون مقبول.
3. افحص على المقاسات الستة قبل أن تنتقل للصفحة التالية.

## المقاسات (CSS px)
| العرض | لماذا |
|---|---|
| 320 | حد WCAG 1.4.10: لا تمرير أفقي |
| 360 | أشيع عرض أندرويد |
| 390 | آيفون حديث |
| 414 | أكثر مقاس في السعودية (27.46%) |
| 768 | لوحي |
| 1280 | سطح مكتب |

## القواعد
| القاعدة | المصدر |
|---|---|
| `<meta name="viewport" content="width=device-width, initial-scale=1">` بلا منع تكبير | البند 16 |
| صفر تمرير أفقي عند 320 | WCAG 1.4.10 |
| النص يكبر إلى 200% بلا فقد: مقاسات بـ`rem`، لا ارتفاعات ثابتة لصناديق النص | WCAG 1.4.4 |
| لا قفل اتجاه | WCAG 1.3.4 |
| كل هدف لمس 24×24 على الأقل؛ الأزرار الأساسية نحو 48 | WCAG 2.5.8 و web.dev |
| ارتفاع الواجهة بـ`svh` لا `vh` | البند 16 |
| الشريط السفلي يبتعد بـ`env(safe-area-inset-bottom)` | MDN |
| صورة الواجهة: `<img>` بأبعاد مكتوبة و`fetchpriority="high"`، وباقي الصور `loading="lazy"` | البندان 14 و16 |
| لا `unload`؛ الرجوع يجب أن يكون فوريًا | البند 16 |
| حقول الإدخال بخط 16px أو أكبر | **اقتراح، بلا مصدر رسمي مفتوح** (يُقال إن Safari يكبّر الصفحة عند أصغر منه) |
| نوع الحقل الصحيح: `type="tel"`، `inputmode`، `autocomplete` | اقتراح |

## الفحص الآلي
```bash
node scripts/measure/responsive.mjs <مجلد-المخرجات> <الاسم> <الرابط>
```
| الحقل | الحد |
|---|---|
| `overflowX` | 0 عند كل عرض |
| `tapsUnder24` | 0 |
| `tapsUnder48` | يُسجَّل؛ الأزرار الأساسية يجب ألا تكون منه |
| `textUnder12` | 0 (اقتراح) |
| `fieldsUnder16` | 0 (اقتراح) |
| `h1Lines` | 3 أو أقل عند 320 (اقتراح) |
| `actionInFirstScreen` | صحيح |
| `fixedCoverPct` | أقل من 25% (اقتراح؛ انظر [standards.md](../../docs/research/standards.md) البند 12) |

قياس مرجعي على محرّك المالك كما هو (2026-11-21): لا فائض أفقي في الستة، لا هدف تحت 24، و22 من 46 هدفًا تحت 48، أصغر خط 14px، العناصر الثابتة 10–23% من الشاشة.

## فحص بالعين وباليد
- اللقطات الست: لا نص مقطوع، لا زر ملتصق بالحافة، العنوان لا ينكسر كلمةً كلمة.
- **جهاز آيفون حقيقي.** الفحص الآلي يعمل على Chromium فقط، و Safari نحو 38.5% من جوالات السعودية. لم نستطع تشغيل WebKit في بيئة العمل. يفتح المالك الرابط التجريبي على آيفون وعلى أندرويد قبل الاعتماد.
- تدوير الجهاز، وتكبير خط النظام، وفتح لوحة المفاتيح على نموذج الطلب.

## لم يُتحقق منه
هل يحتاج `env(safe-area-inset-*)` إلى `viewport-fit=cover` · سلوك Safari مع الحقول الصغيرة · Samsung Internet و UC (نحو 5% معًا).
