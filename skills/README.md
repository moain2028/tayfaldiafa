## ما يتغير بتغيّر فئة الموقع وما لا يتغير
| ثابت لأي فئة | يتغير |
|---|---|
| طريقة العمل: الذاكرة في المستودع، لا حقيقة بلا مصدر، لا «تمّ» بلا دليل | حقائق النشاط كلها |
| دراسة المراجع بالقياس قبل الرأي | من هم المنافسون وما المراجع |
| مواصفة أول شاشة وطريقة فحصها | الصورة والعنوان والدعوة |
| قواعد العربية والوصول والأداء | الخطوط والألوان (قرار المالك) |
| البوابات الآلية | نوع البيانات المهيكلة، ووسيلة التحويل |
| ترتيب المحطات كأسئلة في ذهن الزائر | أسئلة تلك الفئة وأجوبتها |

ما يخص الضيافة تحديدًا مكتوب داخل كل مهارة تحت «خاص بالضيافة».

## قواعد كتابة مهارة
1. رأس الملف: `name` · `description` · `version` · `status`.
2. كل قاعدة معها مصدرها: دراسة في [docs/research/](../docs/research/standards.md)، أو قياس، أو «اقتراح».
3. كل خطوة تنتهي بشيء يُفحص. خطوة بلا فحص تُكتب «حكم بالعين: انظر بنفسك».
4. لا حقائق عميل داخل مهارة: لا اسم ولا هاتف ولا مدينة.
5. بعد كل موقع يُبنى: ما خالف المهارة أو نقصها يُكتب فيها، ويُرفع رقم نسختها.
6. المهارة قصيرة. التفصيل والأدلة في ملفات البحث، والمهارة تشير إليها.
